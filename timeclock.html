Sync across devices

Your hours are stored in one private GitHub gist that every device shares. Pulls when you open, pushes when you clock in/out. Last write wins.

Not connected.

First device: paste your token, tap Create new gist, then copy the gist ID. Other devices: paste the same gist ID + their own token, then Connect. The token grants access to your gists only — revoke it anytime in GitHub settings.
